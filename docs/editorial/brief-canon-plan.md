## 4. Canon inicial (provisional)

Estas reglas son un canon de trabajo, no un canon aprobado de marca o de una obra. Se podrán cambiar cuando el propietario editorial y el aprobador estén identificados.

1. **Hecho antes que afirmación.** Todo dato comprobable debe conservar su fuente, fecha de consulta y contexto suficiente para revisarlo.
2. **Trazabilidad visible.** Cada afirmación material se clasifica como `hecho con fuente`, `decisión editorial`, `pendiente` o `no usar`.
3. **Separación de capas.** Brief, canon, borrador, revisión y autorización son estados distintos; no se presenta un borrador como aprobado.
4. **Cero evidencia inventada.** Si falta una fuente, una cita, un dato o un permiso, se deja el campo abierto y se eleva como pregunta.
5. **Fuentes primero.** Se priorizan fuentes primarias u oficiales cuando existan; las fuentes secundarias se identifican como tales y no se presentan como primarias.
6. **Citas responsables.** Las citas, cifras, nombres, fechas y atribuciones no se completan de memoria. Si no pueden verificarse, no entran en la versión publicable.
7. **Voz bajo control.** El tono definitivo, la guía de estilo y cualquier lenguaje de marca requieren confirmación del propietario editorial; este documento no los inventa.
8. **Publicación con puerta.** Publicar es una acción posterior y condicional: requiere un aprobador identificado, aprobación explícita y un canal confirmado.
9. **Cambios registrados.** Toda modificación que altere el ángulo, el alcance, la evidencia o la autorización se anota como decisión nueva, no como supuesto retroactivo.
