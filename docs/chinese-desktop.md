# 中文桌面版与射击游戏

中文版办公室和 Office Strike 使用同一份客户端与服务器构建。进入办公室后按 **F8**，或点击 **FPS · 1V1**，选择双人对战或人机单挑。WASD 移动、左键射击、R 换弹、Space 跳跃；Esc 打开对战菜单，可调整灵敏度和人机强度。

桌面窗口使用 Microsoft Edge 的 `--app=http://127.0.0.1:4600/`，配合独立 `--user-data-dir` 保存登录与游戏偏好。启动器应先启动办公室并等待 HTTP 就绪，再打开窗口；在 Windows 上使用 PowerShell 7 执行含中文的 UTF-8 启动脚本。部署时一并更新 `bin`、`dist` 和依赖，不要只复制客户端。服务器与原办公室使用相同项目、数据目录和端口，已有桌位与 Agent 会通过现有终端恢复机制恢复。

构建复用本机中文版已有的翻译：`build/chinese-literals.json` 和 `build/chinese.ts` 处理 UI 与场景标签中的静态文案、模板插值，保留当前构建的变量表达式；`src/client/public/assets/zh-cn.js` 与字典处理动态 DOM 文案。终端、代码、聊天和任务正文保留用户原文。每次构建都包含中文资源，不依赖安装后修改带哈希的文件。

如果浏览器不支持鼠标锁定，拖动视角的同时仍可用 WASD 移动、左键射击。支持锁定的桌面窗口点击画面后使用正常鼠标瞄准。移动与射击仍受窗口焦点、对话框、回合阶段和服务器判定约束；等待第二位玩家、倒计时和回合结算期间无法开枪。

验证：`npm run typecheck`、`npm test`、`npm run build`，以及 `node tests/fps-chinese-browser.mjs`（运行已构建的测试办公室）。浏览器测试检查中文办公室与游戏界面、用户内容保护，并分别检查鼠标锁定和拖动模式下真实键盘/鼠标事件到服务器的移动和弹药变化。
