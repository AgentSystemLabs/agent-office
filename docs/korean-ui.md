# 한국어 화면 사용 안내

이 브랜치는 Agent Office의 화면 문구를 한국어로 제공합니다. 로그인, 캐릭터 설정, 프로젝트 추가, 직원 고용, 작업 대기열, 회의, 설정, 변경 파일 확인, GitHub 게시판과 주요 도움말을 자연스러운 한국어로 정리했습니다. 2D 화면(`/lite`)에도 적용됩니다.

Claude Code, Codex, OpenCode, GitHub, 모델 이름, Git 명령어, 브랜치와 파일 경로는 원래 표기를 사용합니다. 저장소의 문서·이슈·댓글, 사용자가 작성한 내용, 에이전트의 터미널 출력과 실제 작업 지시 내용은 원문을 유지합니다.

## 시작하기

1. 사무실 비밀번호로 로그인하고 표시 이름과 캐릭터를 선택합니다.
2. 좌측 상단 프로젝트 이름 또는 엘리베이터에서 작업할 저장소를 선택합니다. 저장소는 서버를 실행하는 컴퓨터의 프로젝트 저장 폴더에 복제됩니다. 개인 fork를 만들지는 않습니다.
3. 빈 책상 앞에서 **E**를 눌러 직원을 고용합니다. **수정**에서 에이전트, 모델과 추론 수준을 선택할 수 있습니다.
4. **P**로 작업을 지시하고, 책상 또는 직원 목록을 클릭해 터미널을 확인합니다.
5. **C**로 변경 파일을 검토하고 **N**으로 응답을 기다리는 직원에게 이동합니다. 전체 조작법은 **H**로 확인합니다.

동시에 여러 직원이 파일을 수정한다면 **별도의 Git worktree와 브랜치에서 작업**을 선택해 작업 공간을 나눌 수 있습니다. 기본값은 공용 프로젝트 폴더에서 작업합니다.

## 빌드와 업데이트

기존과 같이 `npm ci` 또는 `npm run build`로 빌드합니다. 별도의 번역 서비스나 API key는 필요하지 않습니다. 이 브랜치의 문구는 빌드 결과에 포함되며, 언어 선택 메뉴는 없습니다.

공식 영어 버전으로 업데이트하거나 공식 릴리스로 다시 설치하면 해당 버전의 화면 문구로 바뀔 수 있습니다. 한국어 화면을 유지하려면 이 브랜치의 소스로 다시 빌드하세요.
